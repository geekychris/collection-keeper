Connecting the app

  1. In Collection Keeper, open Sync server (the cloud button on the home screen).
  2. Enter this server's address: {{.Data.Base}}
  3. Tap Connect. The app shows a code and opens this site; sign in and approve the code. On a computer you can also scan the QR code the app shows with your phone.

The device keeps its own full copy and works offline. It syncs when it starts, a few seconds after each change, and every few minutes while it's open. Disconnecting a device on the Devices page stops it syncing; it keeps what it has.

Developers: the protocol is in docs/sync-protocol.md in the app's repository; the API is under {{.Data.Base}}/api/v1/.
